# Ko'ox Maaya

App web para aprender **maya yucateco** (maaya t'aan) desde el español: lecciones cortas, repaso espaciado, diccionario y guía de sonidos.

**Abrir la app:** https://sebastiancanul455.github.io/koox-maaya/

> Versión inicial publicada. En breve se sube el código fuente completo, las bases verificadas y la versión instalable sin conexión.

Contenido preparado con IA y cotejado con fuentes públicas; las formas marcadas «por confirmar» deben validarse con hablantes. No está validado para uso clínico.
